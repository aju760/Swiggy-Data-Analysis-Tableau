Swiggy Data Analysis using Tableau
Project Overview

This project focuses on analyzing Swiggy food delivery data using Tableau to understand sales performance, customer ordering patterns, restaurant performance, cuisine preferences, and payment methods.

Objectives
Analyze overall sales and average order amount.
Compare sales performance across cities.
Identify the top 10 restaurants based on sales.
Analyze orders by cuisine.
Understand customer payment method preferences.
Explore delivery time and other key performance indicators.
Tools & Technologies
Tableau
Microsoft Excel
Data Cleaning and Data Visualization
Dataset

The dataset is stored in Swiggy.xlsx and is used to create visualizations and analyze food delivery data.

Key Analysis
City-wise Sales Analysis
Top 10 Restaurants by Sales
Cuisine-wise Order Analysis
Payment Method Analysis
Total and Average Amount KPIs
Delivery Time Analysis
Project Files
Swiggy.xlsx – Dataset used for analysis
Swiggy_Dashboard.twb – Tableau workbook
Tableu proj swiggy ajayt.twb – Original Tableau project file
Conclusion

This project demonstrates how Tableau can be used to transform food delivery data into meaningful visual insights. The analysis helps understand sales trends, restaurant performance, cuisine preferences, and payment behavior.
